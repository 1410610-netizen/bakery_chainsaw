# Image Folder

Add bakery photographs here later, for example:

- `hero-bakery.jpg`
- `sourdough.jpg`
- `chocolate-cake.jpg`
- `croissant.jpg`
- `shop-front.jpg`

After adding an image, replace a placeholder `<div class="photo-slot">...</div>` with an image such as:

```html
<img src="assets/images/sourdough.jpg" alt="Fresh sourdough loaf">
```
